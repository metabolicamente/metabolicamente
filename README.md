# Metabolicamente

Metabolic psychiatry: psychiatrists and dietitians working as one team.

## What's here

- `index.html` - the full working demo (landing page, 7-step assessment wizard, and three dashboards: doctor, dietitian, patient). Open it in any browser. English, fictional data.
- `docs/METABOLICAMENTE_BRIEF.md` - project brief and decisions log.
- `docs/METABOLICAMENTE_UX_RESEARCH.md` - the UX/product research report (cited) that drives the design.
- `lovable-export.zip` - full export of Igor's original Lovable prototype (React + Vite + Supabase), kept for reference.
